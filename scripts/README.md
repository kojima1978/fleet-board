# scripts

運用・データ移行用スクリプトを用途別に管理します。通常のアプリ起動では直接操作する必要はありません。

- `database/`：DBのバックアップ、復元確認、復元処理
- `development/`：開発DBの初期化と依存関係の準備。`compose.yaml`から自動実行
- `migrations/`：既存データを現在のDB構造へ移行する処理。Docker起動時に自動実行
- `production/`：本番設定、起動前診断、DB準備、PC移行、本番コンテナーの運用処理

これらは開発・本番のDocker構成やプロジェクト直下の起動用ファイルから呼び出します。個別スクリプトを直接実行すると、必要な環境変数や事前検査を省略する可能性があります。手動バックアップ、復元、移行、本番更新の実行方法は、プロジェクト直下の`README.md`を参照してください。
