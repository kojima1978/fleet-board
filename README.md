# FleetFlow

NFCタグによる社員・車両識別、社用車の利用開始／返却、タイムライン、駐車位置を一画面で管理する社内向けアプリです。

## Dockerで起動

```bash
docker compose up --build
```

起動後に http://localhost:3035 を開きます。初回起動時にPrismaのスキーマ反映とサンプルデータ投入が自動実行されます。

## 主な操作

- `/` 駐車場配置図（メイン画面）
- `/timeline` 車両タイムラインと予定のドラッグ修正
- `/operations` NFC読取、利用開始、返却登録
- 「NFC読取」から社員・車両タグを模擬読取
- 「利用可能」カードまたはタイムライン左の空き車両から利用開始
- 利用中カードから返却先区画を選んで返却
- タイムラインの予定バーを左右へドラッグして15分単位で修正
- 駐車場図面上の車両を空き区画へドラッグして位置修正

全更新は `version` 列を使った楽観的ロックで競合を検出します。画面は5秒ごとに自動更新されます。
