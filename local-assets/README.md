# ローカル専用3Dモデル

このフォルダーは、GitHubへ公開しない私有の3DモデルをFleetFlowで使うための置き場所です。

## 配置方法

1. 利用権限を確認したGLB形式のモデルをUSBでサーバーPCへ移します。
2. ファイル名を`minion.glb`にします。
3. このリポジトリ内の`local-assets/minions/minion.glb`へコピーします。
4. FleetFlowの駐車場画面を再読み込みします。Dockerの再起動や再ビルドは不要です。

モデル本体は`.gitignore`と`.dockerignore`の対象です。GitHub、Dockerイメージ、DBバックアップには入りません。`minion.glb`がない場合や読み込めない場合、3D演出は何も表示せず、FleetFlowの通常機能だけが動作します。

## 推奨条件

- GLB形式（外部テクスチャを使わず、1ファイルにまとめる）
- ファイルサイズ5MB程度、最大25MB
- 5万ポリゴン以下
- `Run`、`Jog`または`Walk`という名前のアニメーションを含める
- モデルの上方向をY軸、正面をZ軸にする

配置図には3体を表示し、約52秒で外周を1周します。最大30fpsで動作し、画面外・別タブ・操作画面表示中は描画を止めます。OSの「アニメーションを減らす」が有効な場合は表示しません。
